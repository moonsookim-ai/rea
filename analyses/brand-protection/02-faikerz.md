## 4. 제품 분해

### 4.1 FAIKERZ — 위조품 제거 (매니지드 서비스)

- **4단계 파이프라인**(홈페이지 Main Features): 데이터 수집(365일 24시간) → 침해 분석(AI 기반 침해 패턴 분석) → **리걸 액션(국내외 제휴 로펌 연계)** → 플랫폼 신고(플랫폼별 자동 일괄 신고)
- 침해 유형: 위조품, 상표 도용, 이미지 도용, 캐릭터 도용. 위조품은 다시 상표·로고 위조, 형태 모방, 정품에 없는 상품 제작, 정품 일부 변조로 나눕니다.
- 탐지 방법(번들 FAQ 문자열): "빅데이터 분석으로 **유사성을 가진 그룹으로 분류** → 위조품 특유의 콘텐츠 패턴 파악 → AI 모델 학습 → 전문가 리뷰와 지속적 데이터 수집으로 모델 강화". 리스팅 클러스터링 → 라벨링 → 지도학습으로 이어지는 루프입니다.
- 커버리지·규모(회사 주장): 네이버·알리바바 등 1,300개 이상의 플랫폼, 보호 브랜드 100개, **월 1,000만 건 이상 수집, 월 10만 건 이상 제거**.

| 플랜 | 대상                           | 기능                                                                                    |
| ---- | ------------------------------ | --------------------------------------------------------------------------------------- |
