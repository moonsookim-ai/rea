## 분석 방법 (REA 워크플로)

1. 헤드리스 Chromium(CDP 9222)으로 세 사이트를 띄우고 `rea list-browser-targets`로 타깃을 확인했습니다.
2. `rea inspect-web-page --include-script-sources --include-accessibility-text --include-storage-keys`로 DOM, 리소스, 스크립트 원문, 스토리지 키를 수동(passive) 캡처했습니다.
3. `rea export-web-scripts`로 스크립트를 파일로 내보냈습니다(위고페어 20개, 페이커즈 35개, 마크비전 34개 파일).
4. `rea analyze-web-bundle --fetch-source-maps`로 프레임워크 지문, 라우트·엔드포인트 후보, 소스맵을 확인했습니다. `rea analyze-javascript-application`으로 모듈 그래프도 만들었습니다.
5. 내보낸 번들에서 URL 리터럴, 라우트 매니페스트, SDK 흔적을 추출했습니다.
6. 보완으로 Playwright 크롤(사이트당 15~45페이지)을 돌려 텍스트, 서드파티 호스트, XHR/fetch를 기록하고 HTTP 응답 헤더를 확인했습니다.

**범위와 한계**

- 로그인이 필요한 영역에는 접근하지 않았습니다. 계정 생성, 폼 제출, 인증 우회, 비공개 API 호출도 하지 않았습니다. 공개 페이지와 브라우저가 내려받은 공개 정적 번들만 분석했습니다.
- 서드파티 코드인 원본 캡처와 번들(수 MB~100MB)은 저장소에 넣지 않았습니다. Evidence ID와 요약만 남겼습니다.
- REA의 passive 캡처는 페이지가 이미 로드된 뒤에 붙기 때문에 초기 네트워크 요청이 `attach_limited`로 비어 있습니다. 서드파티 호출은 Playwright 크롤로 보완했습니다.

### 3. 전 세계 맥락에서 본 시사점 (11·12 문서 요약)

- **시장**: 세계 위조품 교역은 4,670억 달러(세계 수입의 2.3%, OECD·EUIPO 2025)입니다. K-브랜드 침해 교역은 97억 달러, 한국 기업 매출 손실은 61억 달러로 추정됩니다(OECD 2024).
- **업계 재편**: PE 롤업(OpSec→Crane NXT, ZeroFox→Haveli, MarkMonitor→Com Laude)과, 브랜드 보호·사이버 사칭 대응(DRP)의 융합(Doppel $70M, Allure $17M)이 진행 중입니다. 마크비전은 Series B $48M(2025-09)과 ARR $22M으로 글로벌 2군에서 1군 진입을 노리는 위치입니다.
- **규제 순풍**: 한국 상표·디자인 징벌배상 5배(2025-07), 해외발 위조품 국내 반입을 '사용'에 포함(2025-05), 해외 플랫폼 국내대리인 의무(2026), EU DSA 신뢰 신고자, 미국 INFORM Act 첫 집행.
- **자동화의 병목**: 공식 신고 API는 eBay VeRO 정도입니다. 대부분은 웹 포털 일괄 제출이고, 네이버·쿠팡·11번가는 공개 API를 확인하지 못했습니다. 그래서 "신고 자동화"는 실제로 **포털 자동화(RPA)와 플랫폼 파트너십** 역량을 뜻합니다.
- **기술 표준 조합**: 비전 임베딩(SigLIP 2, DINOv2/v3)과 벡터 DB로 후보를 찾고, 오픈 어휘 검출(OWLv2, Grounding DINO)로 로고를 국소화합니다. pHash/PDQ로 공식 이미지 재사용을 잡고, 셀러 그래프 군집을 쓰며, 멀티모달 LLM으로 근거를 서술하고 신고서 초안을 만듭니다. 최종 판정은 전문가가 검수합니다. **경쟁 해자는 모델이 아니라 테이크다운 결과로 쌓은 라벨과 셀러 DB, 그리고 플랫폼 관계**입니다.
- **수요 이동**: 플랫폼이 스스로 위조품 대부분을 사전 차단하는 추세입니다(네이버 95.6% 사전 차단, TikTok Shop 상반기 4천만 건 거절). 그래서 가치가 SNS·폐쇄형 채널, AI 쇼핑 어시스턴트 노출, 오프라인·소송·손해배상 회수로 옮겨 가고 있습니다. 마크비전의 MarqLaw와 Brand Intelligence Agent, 위고페어의 시험구매와 Shield 모듈 확장은 이 이동에 대응하는 움직임입니다.

### 4. 후발 주자·신규 구축 관점의 기회 [추론]

1. **결과 지표 판매**: 국내 두 회사는 아직 차단 건수를 보고합니다. Saturation Rate형 지표와 '위험 매출' 추정을 리포트에 넣으면 차별화할 수 있습니다.
2. **국내 플랫폼 포털 자동화와 증거 표준화**: 네이버·쿠팡·11번가 신고 포털을 자동화하고, WACZ 아카이브·SHA-256·RFC 3161 타임스탬프로 증거 패키지를 만드는 영역입니다. 아키텍처는 12 문서 5~6장에 있습니다.
3. **그레이마켓/MAP SaaS**: Sselly 영역은 국내에 경쟁자가 적고 셀프서비스형 과금에 맞습니다.
4. **대화형 에이전트 레이어**: 셀러·플랫폼·도메인 데이터를 근거로 질의응답하는 에이전트는 국내에서 아직 공백입니다.
5. **주의**: 로그인 데이터 수집, 자동 계정 생성, 접근 제한 우회는 부정경쟁방지법 데이터 조항(카목)과 판례(잡코리아 v 사람인, 야놀자 v 여기어때)에 따른 리스크가 있습니다. 공식 API를 먼저 쓰고 공개 데이터만 수집하는 원칙을 지켜야 합니다(12 문서 1장).
